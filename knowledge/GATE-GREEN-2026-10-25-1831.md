chunk length, and bytes 0 to 35 (signature plus the whole IHDR block, so width, height, depth, colour type,
compression, filter, interlace) are equal in both files. That is the class `pytest.ini` line 9 already names for
`host_png_bytes`: "the test compares a PNG this host writes with the committed copy byte for byte ... The pixels
agree; the encoder does not". Neither row carries that marker, so `tests/conftest.py` line 112 does not skip it
on Pine and the gate can never be green while they stand. Card `t_78db3b2c` carries the marker fix.
