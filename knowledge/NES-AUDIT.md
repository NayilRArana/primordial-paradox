# NES audit: every art asset against the PPU rules

Generated by `tools/nes_audit_all.py`. Do not edit by hand: rerun the tool.

Ground rule this audit serves: every asset in this project is original work drawn to the NES rules, and nothing is copied from a published game (PLAN-V2-2026-10-21.md section 0). The checker proves the RULES, not the taste: a frame that passes this page can still look wrong, and that judgement is the manager's, by eye.

Failures by class: **no failures at all**. One red number is not one kind of red, so it is never printed as one: a `frame` or an `asset` red is shipped art and it gates, while a `sheet` or a `capture` red is a viewing aid and it is advisory. The table above is that split, and a class with no files in this run is left out rather than printed as a zero.

Exit code from `tools/nes_audit_all.py`: 0. A gated row is a shipped asset or a finished 256x240 frame. A sheet or a window capture is ADVISORY: a 3x contact sheet and a window capture carrying the compositor's own scaling measure a viewing aid and the capture path before they measure the art, so their rows carry their own verdict and are never counted as a pass.

Sorted by how visible each failure is. The count is the pixels a fix has to repaint: a block's pixels that are not among its three most common colours, an off-palette colour's pixels, or the excess beyond 25 colours; the percentage is that count over the visible image.

## Reproduce

    python tools\nes_audit_all.py                 # audit, rewrite this page, exit 1 on a gated failure
    python tools\nes_audit_all.py --only title    # one family of files
    python tools\nes_audit_all.py --quiet         # the CI gate: one line, exit code only

One JSON per file: `output\nes_audit\<path with __ separators>.json`. Summary: `output\nes_audit\SUMMARY.json`.
